# Joe Pye Weed (`Eutrochium`) — research brief

A structured HTML report on Joe Pye Weed, written for a ~5 acre Gleneden farm in Salmon Arm, B.C. seeking BC Assessment farm classification ($2,500 farm-gate on this parcel size). Pond margin, high water table, B.C. status of spotted Joe Pye, and a throughput plan rather than a profit-max plan.

**Read it here:** https://thefrozenfire.github.io/joe-pye-weed/

Open `index.html` locally if you just want the file.
